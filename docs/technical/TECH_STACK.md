## Účel jednotlivých technologií a nástrojů
### Java
Hlavní programovací jazyk backendové části projektu.

### Spring Boot
Framework používaný pro vývoj backendové aplikace a REST API.

### Spring Data JPA
Technologie používaná pro práci s relační databází prostřednictvím JPA repository vrstvy.

### Maven
Nástroj pro správu závislostí a build procesu projektu.

### IntelliJ IDEA Community
Primární vývojové prostředí (IDE).

### MySQL
Relační databáze používaná pro ukládání dat bankovního systému.

### DBeaver
Nástroj pro správu databáze, spouštění SQL dotazů a ověřování výsledného stavu dat.

### JUnit
Framework používaný pro automatizované testování backendové aplikace.

### Postman
Nástroj používaný pro manuální testování REST API.

### Jira
Nástroj používaný v projektu jako simulace evidence požadavků, úkolů, testovacích scénářů a bug reportů.

### Excel
Nástroj určený pro evidenci testovacích scénářů, testovacích dat a výsledků testování.

### Git
Systém pro správu verzí zdrojového kódu a projektové dokumentace.

### GitHub
Vzdálený Git repozitář projektu.

### WSL
Linuxové prostředí používané ve Windows pro práci s terminálem a vývojovými nástroji.
